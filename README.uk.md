# ⚓ Prystan

**Docker і ваші сервери в одному нативному вікні.**

Швидкий десктопний клієнт для Docker через локальний сокет, TCP або SSH —
контейнери, логи, файли, термінали й сама хост-машина.

## Навіщо

Керувати контейнерами на кількох серверах зазвичай можна трьома незручними способами:
заходити по SSH на кожен і набирати `docker` руками, ставити веб-панель **на сам прод**,
або запускати Docker Desktop і віддавати йому 2 ГБ пам'яті.

Prystan — це **бінарник на 13 МБ, що займає ~40 МБ RAM**, підключається до будь-якого
Docker-демона по SSH **нічого не встановлюючи на сервер**, і збирає логи, файли,
термінали й метрики хоста в одному вікні.

## Що вміє

**Підключення** — локальний сокет, TCP (з TLS) або SSH-тунель. Профілі самі
відновлюються після перезапуску й перепідключаються при обриві. Режим **read-only**
для окремого профілю захищає прод від випадкових змін.

**Контейнери** — групування по compose-стеках, старт/стоп/рестарт/пауза/kill, масові
дії, health-бейджі, швидкі фільтри, живі CPU та RAM.

**Логи** — стрім у реальному часі з підсвіткою помилок, яка розуміє **багаторядкові
traceback'и цілком**, фільтри за рівнем і **пошук по всій історії на сервері**, а не
лише по видимому буферу. Зведені логи всього стека в одному потоці.

**Файли** — перегляд, редагування з підсвіткою синтаксису, завантаження, перейменування,
chmod і drag-and-drop — і всередині контейнерів, і на файловій системі хоста.

**Термінали** — кілька сесій на об'єкт, підказки з історії в стилі PowerShell, справжнє
доповнення по `Tab` (з власною реалізацією для шелів на кшталт `dash`, де його немає),
сніпети й повноцінний shell хоста по SSH з робочим ресайзом.

**Сервер** — живі CPU/RAM/диски зі спарклайнами, список процесів із kill, файловий
менеджер і термінал хоста. Метрики йдуть однією постійною ssh-сесією.

**Образи й обслуговування** — розбір по шарах, сканування вразливостей через Trivy,
використання диска з prune, build із Dockerfile, приватні реєстри з push, перестворення
контейнера зі зміненими env, ліміти ресурсів на льоту.

**Ще** — командна палітра (`Ctrl+K`), проброс портів із «відкрити в браузері», журнал
дій, сповіщення в Telegram, світла й темна теми, інтерфейс українською, російською
та англійською.

## Встановлення

Завантажте `Prystan.exe` з [Releases](../../releases) — це один портативний файл без
інсталятора. Для Windows 10/11 потрібен
[WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) (зазвичай уже є).

### Збірка з коду

Потрібні [Rust](https://rustup.rs/) (stable, MSVC) і Visual Studio Build Tools з
C++ workload. **Node.js не потрібен** — фронтенд це звичайний HTML/JS.

```bash
git clone https://github.com/YuraYarmola/prystan.git
cd prystan/app/src-tauri
cargo build --release
```
